# 計算法・再現方法

## 対象
study31の nf02_1。GFMはBus 1,2,3,7、遠方群は2,3,7の等重み平均。全台τp=1.16,1.18,1.20 s、τq=0.02 s。Pset=[0.5,0.4,0.4,0.4] pu、Bus5負荷コンダクタンス倍率2.461761102780045、系統係数k=1.02990。Bus4の20pu受動シャントを事故投入1.0秒からT=0.15秒後に除去し、線路4–5を開放する。事故軌道はstudy31の保存結果を利用。背景はその事故後系統を新規積分したもの。

## 軸と初期状態断面
横軸θ [rad]は遠方3機の平均内部位相から事故後安定平衡点の平均内部位相−1.5548103219232832 radを引いた値。端子電圧の位相ではない。縦軸Δf [Hz]は遠方3機の内部周波数から60 Hzを引いて平均した値。

52微分状態と14代数状態を持つ完全モデルを使用。初期状態は事故後安定平衡点から作る。遠方3機の内部δへ同じ位相差を加え、Pfiltへ同じ差を加えて指定Δfを作る。このモデルではΔf=1.2 mean(0.4−Pfilt)。機間差は維持する。それ以外の46微分状態（Bus1、Qフィルタ、LCL、電圧・電流制御PI積分状態を含む）は安定平衡点の値に固定。14代数状態のみNewton法で整合させる。初期化時の座標誤差、代数残差、固定状態の不変性をinitialization*.csvに記録。

これは条件付きの有限時間同期回復領域であり、52次元吸引域全体ではない。星は断面上の安定平衡点。ひし形は全状態の鞍点をこの2軸へ投影した位置で、断面上の鞍点とは限らない。丸印は実事故除去状態の投影。実事故軌道も断面から外れるため、軌道上の各点を背景色だけで判定しない。同じ座標に事故除去状態由来の46状態を置く追加比較も実施する。

## 格子・分類・描画
粗格子はθ=[−0.4,−0.15,0,0.4,0.8,1.2,1.6]、Δf=[−0.15,−0.10,−0.05,0,0.05]。平衡点付近・事故除去点付近を追加し、分類が変わるDelaunay辺の中点を細分化。300秒で判定し未判定例は1000秒へ延長する。

回復判定は各機の末尾min(50秒,観測時間/3)の最大周波数偏差<1e−4 Hz、平衡点からの位相誤差<min(0.002 rad,各機の安定点–鞍点角差の0.1倍)、末尾位相幅<0.005 rad。負方向回転は総変位<−2回転に加え、末尾60%を三分した各区間が<−0.2回転かつ回転速度<−1e−4回転/秒。詳細はclassify.pyを参照。有限観測での分類であり無限時間持続を証明しない。PI積分状態には遅い収束があり、混合単位の全状態ノルムを一律閾値で切らない。全状態誤差も診断として保存する。数値失敗は電圧崩壊の証明としない。

点の色は実計算結果。三角形の頂点が同分類ならその色を薄く塗るが、内部すべてを計算したわけではない。頂点分類が混在する三角形は斜線。破線は回復/負回転の二値ラベルを線形補間した遷移位置の目安であり、厳密な分離軌道・吸引域境界ではない。狭い島状領域や格子以下の構造を除外できない。折返しなしの内部位相軌道を表示範囲で切り取り、矢印で時間方向を表示する。

## 数値設定と再現
Julia 1.12.5、provenance内のProject.toml/Manifest.tomlおよび元コードを使用。Rodas5P、A: reltol=1e−9, abstol=1e−11, dtmax=0.005秒。B:1e−10,1e−12,0.0025秒。保存刻み通常0.05秒、開始直後0.02秒までは0.0001秒。微分状態・代数状態・観測量・終了理由をチェックポイントに保存する。

作図のみ: Python(numpy,pandas,matplotlib,scipy)で `python code/analyze.py`、`MPLCONFIGDIR=/tmp/mpl_basins python code/plot.py`。Pythonはローカルでは /home/students1/hashima/sci2026/.venv/bin/python。

追加/再開計算: data/worker_enabled.txtを1にし、Juliaで `--project=provenance code/worker.jl 0 /path/to/python` を実行（worker番号0,1,2）。実際の環境フォルダはprovenanceのProject.toml所在を確認すること。既存completed*.txtとcheckpointsを使い再開。新規再計算では別コピーでcompleted*.txt、results、checkpointsを退避し実行。ジョブ定義とseedはdata/jobs.csvとdata/seeds。coordinate.pyは適応格子追加を進めるので、配布済みの確定ジョブを再計算するだけなら実行不要。

## 解釈上の注意
この断面の初期状態は、人為的に構成した代数整合な状態であり、すべてが指定事故から到達可能とは主張しない。角度・Pフィルタだけを変更して電流やPI状態を保持するため、初期の速い電磁・制御応答を含む。これを隠すための準定常化やPI状態の再調整はしていない。

既存事故軌道との再現照合はanchor_reproduction.csv。異なる保存時刻への線形補間誤差と、共通保存時刻での直接差を別々に記録する。補間によるピーク差を積分誤差と解釈しない。数値精度比較は同じ保存刻みでA/Bを比較する。
