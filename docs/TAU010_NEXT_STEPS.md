# τp=0.1秒の領域：確認済みの事実と次の調べ方

## 現状の解釈

- 35点すべてが、位相を2π周期で比較する既存の有限時間回復基準を満たした。
- 終端位相の枝を分けると、26点は全台とも参照枝、9点はBus1が参照枝・Bus2/3/7が参照−2πの枝だった。前の全域青色はこの区別をまとめていた。
- これは終端枝の分類であり、参照枝に終わる点について途中の全位相履歴の無スリップを証明するものではない。
- 鞍点の不安定固有値は+0.0909122 s⁻¹、不安定モードは1個。固定した46微分状態のうち27状態が鞍点では異なる（成分差>1e−8という数値的な確認）。したがって、ひし形の2座標を現在の断面に与えても、全状態の鞍点にはならない。
- 鞍点の存在だけでは、持続回転する開いた初期値領域の存在は保証されない。両側の軌道が位相周期を変えて再同期する可能性もある。
- 最も遅い安定固有値実部は約−0.00183243 s⁻¹（約546秒の減衰時定数）。150秒以内の内部位相・周波数回復は全PI状態の収束を保証しない。

## 優先する追加検討（未実行）

1. **実際の鞍点を基準にする。** DAEの14代数変数を消去した52次元の線形化行列を使い、不安定右固有ベクトルv_uを得る。混合単位の状態は物理的なスケールで正規化する。鞍点の微分状態に±εv_uを与え、代数変数だけ再整合化して両側の行き先を確認する。複数のεで近傍の滞在時間も確認する。
2. **位相枝の境目を追う。** 異なる終端枝の初期状態の間を、微分状態で二分して代数再整合化し、枝分類で絞り込む。持続回転と回復を分ける境界なのか、再同期までの位相移動を分ける境界なのかを区別する。近傍では早期の回復判定を保留し、位相・周波数に加えてPI出力や正規化した状態残差の時間変化を確認する。
3. **鞍点を通る少数の断面を選ぶ。** 不安定方向×事故除去状態へ向かう方向など、物理的に意味のある2方向を使う。現在の平衡点断面を保つ場合は、残り46状態を平衡点から事故除去状態、あるいは鞍点へ補間した断面を数枚比較する。補間は微分状態について行い、代数変数は解き直す。
4. **持続回転解を別に探索する。** τp=1.2秒の回転状態を出発点にτpを段階的に下げ、回転が維持される範囲・再捕捉される範囲を追う。τp=0.1秒で回転解が存続するなら、その状態から回復側との境界探索を始める。単一の初期値族で見つからないことを、回転解の不存在とは解釈しない。

高次元で全方向を格子化するより、まず1と2で鞍点の役割と分類対象を確かめる。二分探索による境界追跡の参考例はSkufca, Yorke, Eckhardt (2006), *Edge of Chaos in a Parallel Shear Flow*, https://doi.org/10.1103/PhysRevLett.96.174101 。流体系の手法を今回のDAE・終端枝分類に合わせて使う提案であり、適用結果はまだ得ていない。
