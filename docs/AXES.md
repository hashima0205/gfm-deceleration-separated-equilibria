# 図の軸と測定量

`figures/tau_comparison.pdf/png` の横軸は事故除去後時間[s]。0は絶対時刻1.15秒の切替直後。上段縦軸はBus2・3・7の内部角変化の等重み平均[回転]、下段は内部周波数偏差の平均[Hz]。固定60 Hz同期座標系で、Bus1基準ではない。各ケースで事故除去時の平均内部角を差し引く。異なる時定数の曲線は異なる動力学であり、1つの吸引域の軌道比較ではない。

各機図の横軸も事故除去後時間[s]。左上は各機内部角の変化[回転]、右上は内部周波数偏差[Hz]、左下は端子電圧の大きさ[pu]、右下はコンデンサ側測定有効電力Re(Vc conj(Ig))[pu]。水平点線は各機P指令。端子側電力Re(U conj(Ig))とコンデンサ側電力はフィルタ損失等により異なる。

内部角は端子電圧位相とは別。端子位相は各機ごとにunwrapし、電圧が0.1 pu未満のサンプルに信頼性不足フラグを付ける。内部周波数は端子位相の数値微分ではない。

保存点を作図前に追加間引きせず、そのまま描く。保存点間で未捕捉のピークがあり得る。集計値から時系列を合成しない。線が図中で終わるのは計算終了時刻の違いである。
